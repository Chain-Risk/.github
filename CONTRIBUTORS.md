# Contributors

Chain-Risk is built with the help of people who contribute code, tests,
documentation, reviews, design feedback, security research, and community
support.

We value contributions of every size and recognize work based on its impact,
quality, and the care taken to improve the project.

## Recognition

- GitHub's contributor graph and contribution history provide an ongoing record
  of accepted code contributions.
- Release notes may acknowledge contributors whose work is included in a release.
- Maintainers may highlight substantial non-code contributions in project
  announcements or documentation, with the contributor's consent.
- Contributors should be credited accurately and in accordance with the
  applicable license and upstream attribution requirements.

## What counts as a contribution?

Examples include:

- Code, tests, bug fixes, and performance improvements.
- Documentation, examples, and tutorials.
- Reproducible bug reports and thoughtful feature proposals.
- Code review, issue triage, and design feedback.
- Security reports and responsible vulnerability research.
- Build, release, and infrastructure improvements.

## Maintainer responsibilities

Maintainers should make a reasonable effort to preserve attribution when
squashing, rebasing, or otherwise integrating contributions. Contributors
should use their preferred public attribution and ensure commit author
information is accurate.

This file describes the recognition policy; it is not an exhaustive manually
maintained list of contributors or a ranking of community members.
