# Chain-Risk `.github`

Organization-wide governance, contribution guidelines, and community health files for **Chain-Risk**.

This repository maintains shared community standards and organizational resources used across repositories under the [Chain-Risk organization](https://github.com/Chain-Risk).

## Purpose

We aim to maintain a consistent, transparent, and welcoming open-source development environment across all Chain-Risk projects.

This repository centralizes shared documentation and GitHub community health files to help contributors understand how our projects are maintained and how they can participate.

## Repository Contents

| Path | Description |
|---|---|
| `profile/README.md` | Public introduction and overview of the Chain-Risk organization |
| `CONTRIBUTING.md` | Guidelines for contributing to Chain-Risk projects |
| `CODE_OF_CONDUCT.md` | Community behavior and participation standards |
| `SECURITY.md` | Security vulnerability reporting guidelines |
| `SUPPORT.md` | Guidance for getting help and support |
| `FUNDING.yml` | Funding and sponsorship information, when configured |
| `ISSUE_TEMPLATE/` | Shared issue templates |
| `PULL_REQUEST_TEMPLATE.md` | Pull request guidelines and template |

*Some files may be added as the organization and its projects evolve.*

## Contributing

We welcome contributions from developers, security researchers, and open-source enthusiasts.

Before contributing to any repository:

1. Review its contribution guidelines.
2. Check existing issues and pull requests.
3. Follow the project's coding and testing conventions.
4. Provide clear descriptions of proposed changes.
5. Be respectful and constructive in community discussions.

For project-specific instructions, always refer to the respective repository.

## Our Projects

Explore the repositories maintained under [Chain-Risk](https://github.com/Chain-Risk).

We are building open-source tools and capabilities around software supply-chain security, dependency intelligence, and risk analysis.
