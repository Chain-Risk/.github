# Support

Thanks for using Chain-Risk projects.

## Where to get help

- **Bug reports:** Open an issue in the affected repository with reproducible
  steps, expected behavior, actual behavior, and relevant version information.
- **Feature requests:** Open an issue describing the use case, expected outcome,
  and alternatives considered.
- **Usage questions:** Check the repository README and documentation first. If
  the question is not answered there, use the relevant repository's public issue
  tracker.
- **Contribution questions:** Read `CONTRIBUTING.md` and ask in the relevant
  issue or pull request.
- **Security vulnerabilities:** Do not use public issues. Follow `SECURITY.md`.

Organization: https://github.com/Chain-Risk

## Helpful information to include

When requesting support, include:

- Repository and version or commit.
- Operating system and relevant runtime/tool versions.
- Minimal steps to reproduce the problem.
- Sanitized logs and error messages.
- What you expected and what happened.

Remove access tokens, credentials, private keys, personal information, and
sensitive infrastructure details before posting.

## Support boundaries

Chain-Risk is an open-source initiative. Support is provided by contributors
and maintainers on a best-effort basis; no response time or commercial support
service is guaranteed.
